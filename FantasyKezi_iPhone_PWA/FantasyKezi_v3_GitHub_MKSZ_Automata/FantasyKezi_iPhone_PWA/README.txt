Fantasy Kézi – iPhone PWA

1. A csomag tartalmát töltsd fel egy HTTPS webtárhelyre (pl. GitHub Pages, Netlify).
2. iPhone-on SAFARI böngészőben nyisd meg a közzétett index.html címet.
3. Megosztás > Hozzáadás a Főképernyőhöz.
4. Az első megnyitás után az alkalmazás alapfunkciói internet nélkül is működhetnek.

Fontos: a ZIP-fájl iPhone-ra másolása vagy a helyi index.html megnyitása NEM telepít PWA-t. HTTPS szükséges a service workerhez.
Az MKSZ közvetlen adatlekérése kísérleti, nem igazoltan működő élő szinkron. A kézi import és a klubstátuszok ellenőrzése szükséges.
A játékosok és a beállítások a készülék böngészőjének helyi tárhelyén vannak; Safari adatainak törlése ezeket törölheti. Használd a JSON exportot mentéshez.
